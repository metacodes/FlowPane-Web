# FlowPane 1.0.5

## New Features

- Added configurable switcher settings.
- Added current-application switching in Preview Grid with forward and reverse shortcuts.
- Added automatic updates.
- Added guided first-run onboarding for permissions and shortcuts.

## Fixes

- Improved screen capture permission handling.
- Reduced preview prewarming delays and improved capture timing and reliability.
- Improved event-tap and shortcut reliability.
- Improved window activation reliability.

## Improvements

- Optimized preview capture performance, concurrency safety, and hardware API usage.
- Improved Space compatibility, WindowServer integration, and preview presentation.
- Refined onboarding window presentation and application icon masking.
