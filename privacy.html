FlowPane privacy FlowPane 隐私说明

Your windows stay on your Mac. 你的窗口，只留在 Mac 上。

FlowPane requests only the macOS permissions needed for the switching experience you choose. FlowPane 仅请求你所选择的窗口切换体验真正需要的 macOS 权限。

Accessibility 辅助功能

Accessibility is used only when FlowPane focuses and raises the real window you select. It is not used to read window contents. 辅助功能权限仅用于聚焦并置前你选择的真实窗口，不用于读取窗口内容。

Screen Recording 屏幕录制

Screen Recording is used only to create Preview Grid thumbnails locally on your Mac. FlowPane does not upload those previews. Compact List works without this permission. 屏幕录制权限仅用于在你的 Mac 本地创建预览网格缩略图。FlowPane 不会上传这些预览，紧凑列表无需此权限。

This website 本网站

This static website has no analytics, advertising, cookies, forms, accounts, or remote localization. A manual language choice is stored only in your browser. 这个静态网站不使用分析统计、广告、Cookie、表单、账户或远程翻译服务。手动语言选择只保存在你的浏览器中。

Proprietary software 专有软件

FlowPane is proprietary software. Its public GitHub repository contains this website and release downloads, not the application source code. FlowPane 是专有软件。公开 GitHub 仓库仅包含本网站与版本下载，不包含应用源代码。
